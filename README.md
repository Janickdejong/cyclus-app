# Cyclus (Android)

De Sensiplan-cyclusapp als lokale Android-app: geen account, geen server. Alle gegevens staan op de telefoon.

- Download de nieuwste `Cyclus.apk` via **Releases** en installeer hem.
- Gegevens overzetten uit de webversie: daar *Download back-up*, hier *Back-up terugzetten*.
- Back-up: Instellingen → *Back-up opslaan of delen* → kies Google Drive.

De webpagina staat in `app/src/main/assets/www/index.html` en is afgeleid van de webversie in de repo `cyclus`.
